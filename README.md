# Java-Lagerverwaltung

Ein bewusst kleines Java-Konsolenprojekt zum praktischen Lernen von Programmiergrundlagen.

## Aktueller Stand

Die Anwendung zeigt ein einfaches Konsolenmenü für typische Schritte einer Lagerverwaltung an: Produkt hinzufügen, Produkt anzeigen, Bestand ändern und beenden. Sie ist als Lernprojekt eingeordnet und noch keine vollständige Warenwirtschaft.

## Starten

Voraussetzung ist ein installiertes JDK.

```powershell
javac Main.java
java Main
```

Die dabei erzeugte Datei `Main.class` wird nicht versioniert.

## Nächste Lernschritte

- Eingaben über die Konsole verarbeiten
- Produkte und Bestände als Klassen modellieren
- Datenstrukturen und Validierung ergänzen
